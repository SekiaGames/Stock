# 高股息列表
一个精简版 InStock Web 应用，仅保留高股息列表相关功能。
项目仅考虑沪深主板股票。
原仓库地址：https://github.com/myhhub/stock

## 功能
- 读取 `instock/config/stocklist.txt` 中的股票代码。
- 拉取并缓存行情价格。
- 股息率≥4%的股票为高关注度：盘中行情每次轮询刷新（约5分钟一次），其余股票每6次轮询
  （约30分钟）才刷新一次，首次轮询全部刷新；高关注度列表写入 `instock/config/high_attention_daily.txt`（每日清空重写）。
- 前端展示高股息组合核心参数、过滤器，用于选股和趋势分析。
- 优先请求屏蔽相关数据（行业、收益、息增年），被屏蔽的股票不再请求其余数据。
外部请求间隔：东财约1秒、腾讯约0.4秒。

## 配置股票列表
instock/config/stocklist.txt
每行一个股票代码，可带名称：
600900 长江电力
包含沪深主板全部约3200只股票。

instock/config/followlist.txt
点击股票名称可添加关注，没有followlist.txt时自动创建。

个股分析页（/instock/stock?code=XXXXXX）
点击高股息列表中的股票代码进入自建个股分析页（新标签打开），包含：
- K线走势图（ECharts candlestick，前复权，红涨绿跌）+ MA120 辅助线 + 成交量副图 + 流动性指标叠加层
  （右侧0~100纵轴，逐日滚动120日窗口计算，叠加在主图上，与列表页流动性列同口径）+ 缩放滑块，
  时间轴默认展示最近1年（250根日K，独立缓存 cn_high_dividend_detail_kline_cache，不受列表页125根缓存截断）；
  首次打开页面时按需抓取250根补齐，不足1年的次新股返回实际可用根数；
  悬停K线显示当日开/高/低/收、涨跌幅、换手率（总股本口径）与MA120位置；
- 顶部指标条：现价、涨跌幅、股息率、息增年、季报（Q1~Q4）、扣非、FCF/股息、市值、行业，
  股票代码可点击跳转雪球网；
- 数据来自各缓存表，页面每60秒静默刷新。

instock/config/blocklist_industry.txt
instock/config/blocklist_industryStocks.txt
每行一个需要屏蔽的申万二级行业，一般是不能出口的下行行业。
对于银行业，建议直接参考银行ETF易方达。
屏蔽行业对应的股票缓存，避免重复判断行业。
如需解除屏蔽，可手动编辑blocklist_industry.txt后删除股票缓存。

instock/config/blocklist_negativeEps.txt
收益（最新已完结财年年报的稀释每股收益）为负或0的股票自动记录到此文件并屏蔽。

instock/config/blocklist_dividendYieldBelowTwo.txt
instock/config/blocklist_dividendGrowthYearZero.txt
股息率低于2%的股票自动记录到此文件并屏蔽。
息增年为0的股票自动记录到此文件并屏蔽，新上市无分红公司（派息历史凑不出2个财年）同样屏蔽。

instock/config/signal_notify_daily.txt
买卖点信号通知文件，由后台定时刷新或页面请求在信号触发时实时写入（盘中）。
后台调度默认每 5 分钟执行一次（见 instock/config/scheduler.conf），未打开前端时同样写入；
供外部程序（如QQ机器人）读取转发。
第一行为当天日期，之后每行按信号触发顺序排列（信号标签带写入时间）：
买入信号·上午9点11分：000680｜山推股份、现价10.84、涨跌幅-4.91%、MA120位置-4.2%、股息率3.6%、扣非10.0%、息增年1、FCF/股息110%、市值100、电力
卖出信号·下午2点30分：000680｜山推股份、现价10.84、涨跌幅+4.91%、MA120位置+4.2%、股息率5.2%、扣非-8.5%、息增年1、FCF/股息85%、市值66、电力
字段依次为：信号方向+写入时间、代码、名称、现价、涨跌幅、MA120相对位置、股息率、扣非、息增年、FCF/股息、市值、行业。
各字段格式化与前端显示一致：现价2位小数、涨跌幅带正负号2位小数、MA120位置带正负号1位小数、
股息率/扣非1位小数、FCF/股息整数百分比、息增年/市值整数。
缓存缺失的字段显示 --（股息率/息增年需财报与派息缓存已抓取，首次可先打开页面触发抓取，或等待后台定时刷新完成）。
每只股票每天只触发一次（去重，盘中反复跨越阶段边界不重复记录）；
跨天后首次写入会重写文件，只保留当天信号。文件不存在时自动创建。
写入后可通过 NapCat 推送到 QQ 群（配置文件 instock/config/qq_push.conf，部署见 README_NapCat.md）；
推送失败不影响文件写入。

instock/config/signal_filter.txt
买卖点信号写入过滤条件，不满足任一条件的信号不写入 signal_notify_daily.txt。
文件不存在时服务启动自动创建默认规则，修改后即时生效，无需重启：
  扣非>-10   （最新季报扣非净利润同比增长，低于-10%不通知）
  股息率>3   （低于或等于3%不通知）
  FCF/股息>50（覆盖率低于或等于50%不通知，FCF/股息配置按百分比）
每行一个条件：字段 操作符 阈值（支持 > >= < <=），# 开头或空行忽略；
删除对应行即关闭该过滤。字段缺失（缓存未抓取）视为不通过。

instock/config/report_season.txt
财报季列（名称右侧Q1~Q4列）的开关与披露季日期范围，日期精确到日、不写年份（MM-DD，含首尾当天）。
第1行为是否开启该列：开 或 关；之后每行一个披露季窗口：起始日期 结束日期（如 07-01 08-31）。
年份自动计算：窗口起始月的前一个月末即目标报告期（1月窗口=上年12月末=上年年报），
列名按报告期自动生成（如报告期2026-06-30 → 列名26Q2），无需跨年更新。
窗口日期重叠时按行序取最后一个命中（默认4月年报与一季报重叠，一季报在后，显示当年Q1）。
文件随仓库常驻（默认1-3月年报季=上年Q4、4月=当年Q1、7-8月=当年Q2、10月=当年Q3），
缺失时报错（该列不显示），修改后即时生效，无需重启。

instock/config/high_attention_daily.txt
高关注度股票列表（股息率≥4%），自动维护、每日清空重写：首行为当天日期，
之后每行 代码 名称。页面打开时按最新股息率重写当天列表；跨天后读取视为空，
重新按当天股息率生成。文件不存在时服务启动自动创建（首行为当天日期，列表为空）。
高关注度股票盘中行情每次轮询刷新一次，其余股票每6次轮询刷新一次（见 腾讯行情 更新频率）。

## 参数解释
名称：派息时显示为绿色，财报时显示为红色，点击股票名可添加/删除关注。
Q1~Q4财报季列：当前扣非是否来自该季报告（是/否），列名与目标报告期由 instock/config/report_season.txt
  的披露季窗口自动计算（默认1-3月年报季显示上年Q4如25Q4、4月显示当年Q1、7-8月中报季显示当年Q2、
  10月显示当年Q3；非财报季或配置关闭/缺失时隐藏该列）。
扣非：最新季报的扣非净利润同比增长，作为业绩参考。
  低于-10%时用浅蓝色背景提示。
旧财年收益（隐藏）：财年基准年份前两年财年年报的稀释每股收益，衡量账面上的盈利能力。
  要注意投资性收益也计入每股收益，现金流才是真实收益。
新财年收益（隐藏）：财年基准年份前一年财年年报的稀释每股收益。
  默认空，检测到该财年年报后不再为空。
  由此判断当前已完结的最新财年：新财年收益非空即最新财年为新财年，否则为旧财年；
  股息率、派息、息增年的最新财年基于此判断。
财年基准年份：存于数据库 settings 表（fiscal_year_base），首次运行时写入当前年份；
  跨年时自动重置，旧财年收益/新财年收益随基准年份平移。
派息（隐藏）：上一个财年的所有派息总和，包括计划中但是未执行的。
现价（隐藏）：盘中实时价格或收盘价。
涨跌幅（隐藏）：现价相对昨日收盘价的涨跌幅，来自行情接口，判断涨跌。
股息率：最新已完结财年（见新财年收益说明）的派息/现价，作为股东回报参考。
  默认最低3%股息率，可在页面调整。
息增年：派息持续增加的年份，0年即最新已完结财年的派息额小于上一年。
FCF（隐藏）：窄口径自由现金流，取最新季报数据（与扣非同报告期，年报季为年报）。
FCF/股息：窄口径FCF/股息，评估自由现金流对股息的覆盖率；金融行业用稀释每股收益/每股派息替代。
  低于0%时用浅蓝色背景提示。
流动性积分：基于交易量基准的累加式流动性指标。核心思想：缩量下跌 = 一点点抛压砸出大跌幅 =
  买盘稀薄、流动性紧张导致的"错杀"（黄金坑机会）；放量上涨 = 真实买盘（超买方向）。
  采用"基准交易量（前120根日均量）+ 当日信号20日滚动累加积分"的公式，逐日滚动。计算过程如下：
  1. 流动性当日（积分前的每日原始信号）= 当日涨跌幅 × (当日基准交易量 ÷ 当日交易量) × 100：
     - 当日基准交易量 = 含当日在内前120日日均成交量，每日单独计算、逐日滚动；
     - 当日涨跌幅 ret = 当日收盘/前一日收盘 − 1（下跌为负）；
     - 当日基准交易量/当日交易量 为量能放大比：当日缩量（< 基准量）时 > 1，放大当日值；
     - 下跌且缩量 → 大幅负值（抛压被流动性放大，超卖/黄金坑方向）；
       上涨且放量 → 正值被缩小（超买方向）。
  2. 流动性积分（20日滚动累加，0分起算）：每日常数单独计算基准——计算某日（T）积分时，
     以前第20日（T−20）为积分0，前第19日~今日共20日逐日累加：
     积分(T) = Σ 当日(T−19 .. T)。
  3. 左侧交易参考（高股息股）：缩量下跌更接近买入信号
  缩量下跌 = 抛压轻、无人接盘，跌的是"没人买"而非"有人砸"：高股息股的长期持有人（险资/价值盘）惜售不撤，
  跌下来股息率被动抬升，流动性恢复后价格自然修复，属"错杀"（黄金坑候选）；
  放量下跌 = 真实卖压/筹码出逃，可能隐含分红能力、行业景气等基本面隐忧，左侧接刀容易接在半山腰。
  注意：短期缩量急跌（几天）错杀概率大，长期地量阴跌（数月）可能是机构缓慢撤离，需配合股息率利差、
  扣非增速验证；最稳的左侧买点是"缩量止跌"（缩量下跌 → 跌幅收敛/横盘抛压枯竭 → 放量反包确认），
  放量下跌中段不接，仅在放量恐慌宣泄后观察。
  本流动性指标的设计逻辑：缩量放大当日负值 → 积分走低到极端区域 = 左侧关注区。
MA120:现价相对于日线MA120的涨跌，评估中长线估值水平。
  买点提示红色背景：
    现价相对昨日收盘价下跌（涨跌幅为负）。
    现价位于MA120相对位置0%以下。
    昨日收盘价/MA120相对位置除以10%后取整 - 现价/MA120相对位置除以10%后取整 > 0
  卖点提示绿色背景：
    现价相对昨日收盘价上涨（涨跌幅为正）。
    现价位于MA120相对位置10%以上。
    昨日收盘价/MA120相对位置除以10%后取整 - 现价/MA120相对位置除以10%后取整 < 0
  昨日收盘价的定义：125根K线的最新一根的收盘价；收盘后当天K线已入库时，
    最新一根为当天、昨日收盘用最新第二根（买卖点提示盘后依然有效）；
    盘前（0点至9点半开盘前）及休市延续盘后提示，同样用最新第二根。
行业：申万二级行业，作为行业板块参考。
市值：流通市值，单位亿，作为风险参考，一般来说低市值企业波动率更大。
派息历史（隐藏）：分红配送相关的公告变化。

### 数据来源与抓取方式
数据按需抓取：只有缓存过期的数据才会重新请求，一次页面刷新会按优先级先抓屏蔽相关数据（行业、收益、息增年），被屏蔽的股票不再请求其余数据。
股息率、息增年依赖年报数据判断财年，等派息历史和收益数据齐了后再计算。

腾讯（批量行情接口）：
- 行情：qt.gtimg.cn，每批100只返回现价、昨收、开盘、最高、最低、成交量、成交额、涨跌幅。
  更新频率：与前端自动刷新同步（每5分钟一次），盘中高关注度（股息率≥4%）股票每次轮询刷新一次、
  其余股票每6次轮询（约30分钟）刷新一次（首次轮询全部刷新，只抓取过期子集），收盘后只更新一次（当日收盘值），
  周末、盘前不更新；页面未打开时由后台调度定时触发（默认每5分钟一次，见 instock/config/scheduler.conf），
  与页面轮询互斥执行（单飞，不重复请求），每次100只，约0.4秒一批。
  买卖点信号通知（signal_notify_daily.txt）随后台定时刷新/前端轮询实时判断写入。

腾讯（批量接口）：
- 市值：qt.gtimg.cn 的field 45（流通市值），单位亿，
  更新频率：周五收盘后刷新，周一至周四保持上周五数据不刷新，每次100只。

腾讯（K线接口，逐股请求，每股一次，前复权日线）：
- MA120、流动性指标：web.ifzq.gtimg.cn，一次请求取125根日K（含开盘价与成交量），
  125根 = 120根窗口 + 盘中排除当日未完成K线1根 + 少量容错余量。
  更新频率：每个交易日收盘后最多一次（页面打开时触发），盘中、周末、假日零请求；
  首次无缓存、停机补数、除息日调整、旧缓存无成交量时重新请求。
- K线原始数据缓存于 cn_high_dividend_kline_cache（含成交量），最多125根/股，多余删除：
  首次无缓存时请求125根；缓存缺最新交易日K线（如容器停机未更新）时重新请求覆盖；
  缓存已含最新交易日（盘中为最近交易日、收盘后为当天）时不再请求外部接口，直接用缓存重算MA120与流动性指标；
  除息日前后复权价整体调整，重新请求覆盖125根。
  周末、假日打开页面不再重复请求K线。
- 流动性指标缓存于 cn_high_dividend_liq_cache，随K线刷新同步计算；
  换手率 = 成交量(手)×100/总股本（财报最新一行 TOTAL_SHARE，总股本口径），
  个股自身历史百分位不受股本口径影响。

东财（批量接口）：
- 派息历史：datacenter RPT_SHAREBONUS_DET，历年分红配送记录。
  更新频率：无缓存时检查一次，16点至23点之间每4小时检查一次。每批10只
- 扣非、收益：datacenter RPT_F10_FINANCE_MAINFINADATA，最新季报扣非净利润同比、上年年报稀释每股收益，同一请求返回。
  更新频率：无缓存时检查一次，16点至23点之间每4小时检查一次，每批20只。
- FCF、FCF/股息：datacenter RPT_DMSK_FN_CASHFLOW，最新季报（与扣非同报告期，年报季为年报）经营现金流净额与购建资产支出，据此计算窄口径FCF。
  更新频率：获取到新收益数据时同步刷新，每批20只。

东财（批量接口）：
- 行业：datacenter RPT_F10_ORG_BASICINFO，申万二级行业。
  更新频率：只在无缓存时请求一次，每次100只，无需刷新。

## 过滤器解释
扣非：不显示扣非低于-10%的股票。
关注：只显示关注列表中的股票，点击股票名可添加/删除关注。
最低股息率%：不显示股息率低于该百分比的股票。
最低市值：不显示流通市值低于该值的股票，单位亿。

# 准备好Docker部署环境
## 终端开启代理（可选）
在～/.zshrc文件中添加一行：
alias daili='export http_proxy=http://127.0.0.1:7897; export https_proxy=http://127.0.0.1:7897; export all_proxy=socks5://127.0.0.1:7897'
端口号改成自己的软件的端口号，运行新的终端，执行daili命令即可。验证是否开启成功：
curl -I https://www.google.com

## 安装Docker app
brew install --cask docker
这个时候程序目录出现Docker图标，可以手动运行，也可以代码运行：
open -a Docker
点击菜单栏小图标可以唤起Docker面板

## Docker app设置
General：开启自动启动、关闭启动时打开Dashboard

## 创建本地常驻文件
mkdir -p "$HOME/instock-mariadb-data"

# 创建Docker容器
## Create Docker network
docker network create InStockService

## Start MariaDB
docker run -d --name InStockDbService \
  --network InStockService \
  -v "$HOME/instock-mariadb-data:/var/lib/mysql" \
  -e MARIADB_ROOT_PASSWORD=root \
  mariadb:latest

## 给本地仓库脚本可执行权限
ls -l /Volumes/Data/Git/Stock/instock/bin/*.sh
chmod +x /Volumes/Data/Git/Stock/instock/bin/run_web.sh
终端输入“chmod +x ”然后把文件拖到终端里生成正确的地址。

## Start InStock
docker run -dit --name InStock \
  --network InStockService \
  -p 9988:9988 \
  -v /Volumes/Data/Git/Stock:/data/InStock \

# 高股息持仓心得
首先必须要介绍高股息之家，关注微信公众号“高股息之家”查看历史消息。
六大原则：
（一）安全边际，股息率需大于无风险利率。
（二）季报原则，扣非不能低于-10%，需保持正常经营。
（三）不择时，股息率自带择时。
（四）低卖高卖，非长期持股，四进三出。
（五）分散持股。
（六）单因子，唯股息论。
十六字诀：
“持股守息，等待过激；若无过激，持股守息”。
一个底线：
如果股息率组合连续两年收益为负，不管负得多么微小，我都会放弃。
因为作为一名全职投资者，我无法接受自己两年没有收入。

介绍本工具的研究思路：
选股：股息率大于3%的企业，每年更新一次列表，A股一般是4月底截止发布完年报。
要综合关注业绩、派息、窄口径自由现金流、日MA120位置、行业轮动、市值区间。
季报扣非低于-10%属于暴雷，需要避开。
派息表示对股东的回报意愿，不是越高越好，也要关注可持续性。
企业财报中的每股收益一般对应企业常态化的盈利能力，基于约定派息比例派息。
自由现金流FCF表示当下的盈利能力，能覆盖派息更好，盈利越强增加派息空间越多。
表中的FCF为窄口径FCF，即财报中的现金流量表中的“经营活动产生的现金流量净额”-“购建固定资产、无形资产和其他长期资产支付的现金”。
  窄口径FCF只扣除刚性支出，通常用于制造业，对于金融行业则使用了稀释每股收益作为替代。
  对于财报中有特殊情况的，可以手动计算窄口径FCF值填入。
日MA120是长线持股关注的重要指标。低于/高于日MA120线10%、摸线，等可能会被判断为买卖点。
  很多科技股长期高位运行，即便跌破MA120，由于没有派息回购，无法确认底部。
  市场缺少流动性时，唯一的潜在买方就是公司自己。
  MA120股指体系，只适用于高股息。因为高股息是一种处境，意味着这家公司没有故事可讲，只能靠真金白银吸引股东。
  对于科技股来说，就是讲故事、吹泡沫，完全可以跌90%，只要不回购不派息就一直跌，跌到有人买为止。
行业轮动，对应着资金对不同板块的偏好。
市值区间反应一定风险偏好，小市值企业波动偏大，可能面临巨大回撤。
